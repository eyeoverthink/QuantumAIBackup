# Quantum Phi-Harmonic Dream Evolution Experiment (Standalone)

This directory contains a standalone version of the successful "AI Dream" experiment. The system demonstrates meta-learning by correcting errors and interpreting abstract anomalies based on phi-harmonic principles.

## Files Included

- `qr_phi_multiples_dream_evolution.py`: The main Python script for the experiment.
- `dream_evolution_summary.md`: A report detailing the final, successful results of the experiment.
- `cascade_opinion_on_quantum_ai.md`: A detailed analysis and perspective on the project's architecture and philosophy provided by the AI assistant, Cascade.
- `requirements.txt`: A list of Python dependencies required to run the script.
- `README.md`: This file.

## How to Run

1.  **Install Dependencies:**
    It is recommended to use a virtual environment.
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    ```

2.  **Run the Experiment:**
    Execute the main script. It will create an output directory named `dream_evolution_one` containing the epigenetic memory, generated scripts, and a visualization of the evolution.
    ```bash
    python3 qr_phi_multiples_dream_evolution.py
    ```

## Overview

This script simulates a self-evolving system that manages random errors and processes an abstract 'dream' anomaly. Its key feature is a positive reinforcement loop that boosts the system's 'resonance' upon successful error correction, allowing it to learn and improve its performance over hundreds of epochs.
