# Quantum MoE/MoA Deep Learning System

This directory contains the Quantum Mixture of Experts/Mixture of Attention (MoE/MoA) deep learning system for the QuantumAI project. The system combines advanced neural network architectures with quantum computing principles to create a powerful, self-evolving AI system.

## Components

### Core Components

- **quantum_moe_moa.py**: Main implementation of the Quantum MoE/MoA system
- **models/moe_moa_core.py**: Core model architecture for the MoE/MoA system
- **evolvers/architecture_evolver.py**: Architecture evolution system for optimizing model structure
- **scrapers/knowledge_scraper.py**: Web scraper for acquiring knowledge from online sources

### Integration Components

- **integrations/quantum_moe_moa_integration.py**: Integration with the main QuantumAI system
- **api/quantum_moe_moa_api.py**: REST API for accessing the MoE/MoA system
- **cli/quantum_moe_moa_cli.py**: Command-line interface for the MoE/MoA system

## Features

- **Mixture of Experts**: Utilizes multiple expert networks with a learned routing mechanism
- **Mixture of Attention**: Combines multiple attention mechanisms for enhanced representation
- **Self-Evolution**: Automatically evolves its architecture based on performance metrics
- **Knowledge Acquisition**: Learns from web sources to continuously improve
- **Quantum Integration**: Integrates with quantum computing principles from the main QuantumAI system

## Usage

### Command Line Interface

```bash
# Process a query
python -m deep_learning.cli.quantum_moe_moa_cli process "What is quantum entanglement?"

# Evaluate the model
python -m deep_learning.cli.quantum_moe_moa_cli evaluate

# Generate a visualization
python -m deep_learning.cli.quantum_moe_moa_cli visualize "Quantum superposition"

# Run a benchmark
python -m deep_learning.cli.quantum_moe_moa_cli benchmark --num-queries 10

# Start the learning process
python -m deep_learning.cli.quantum_moe_moa_cli learn --duration 2

# Get system status
python -m deep_learning.cli.quantum_moe_moa_cli status
```

### API Usage

Start the API server:

```bash
python -m deep_learning.api.quantum_moe_moa_api
```

The API will be available at `http://127.0.0.1:5002` with the following endpoints:

- `POST /api/quantum/moe_moa/process`: Process quantum data or a query
- `GET /api/quantum/moe_moa/evaluate`: Evaluate the model
- `POST /api/quantum/moe_moa/visualize`: Generate a visualization
- `POST /api/quantum/moe_moa/benchmark`: Run a benchmark
- `GET /api/quantum/moe_moa/status`: Get system status

## Integration with QuantumAI

The MoE/MoA system integrates with the main QuantumAI system through the `QuantumMoEMoAIntegration` class. This integration allows the MoE/MoA system to process quantum states generated by the main system and enhance the results with its own processing.

Example:

```python
from deep_learning.integrations.quantum_moe_moa_integration import QuantumMoEMoAIntegration

# Initialize integration
integration = QuantumMoEMoAIntegration()

# Process a query
result = integration.process_query("Explain quantum entanglement")
print(result['combined_metrics']['combined_score'])
```

## Model Architecture

The MoE/MoA model consists of:

1. Multiple expert networks that specialize in different aspects of the input
2. A routing mechanism that determines which experts to use for each input
3. Attention modules that enhance the representation of each expert's output
4. A combination mechanism that merges the outputs of all experts

The model is designed to be self-evolving, meaning it can modify its own architecture based on performance metrics.
