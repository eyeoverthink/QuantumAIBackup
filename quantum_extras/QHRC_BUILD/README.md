# QHRC Build Package

## Directory Structure
```
QHRC_BUILD/
├── 3d_prints/        # STL and G-code files
├── circuits/         # Circuit diagrams and specs
├── experiments/      # Test procedures
└── docs/            # Documentation
```

## Quick Start
1. Print the coil forms (3d_prints/gcode/)
2. Build the circuit (circuits/CIRCUIT.md)
3. Wind the coils (docs/WINDING.md)
4. Run tests (experiments/TEST_PROTOCOL.md)

## Core Frequencies
- Base: 4.37 Hz
- φ⁴: 6.854 Hz
- φ⁷: 29.034 Hz
- Target resonance: 0.96
