# 3D Printing Instructions for Anker Make

## Files
1. primary_coil.stl / .gcode
2. secondary_coil.stl / .gcode
3. base.stl / .gcode

## Anker Make Settings
```
Printer: Anker Make
Material: PETG
Nozzle: 0.4mm
Layer Height: 0.2mm
Infill: 50%
Wall Count: 3
Top/Bottom: 4
Support: Yes
Temp:
- Nozzle: 230°C
- Bed: 80°C
```

## Print Order
1. Base plate first
2. Primary coil
3. Secondary coil

## Print Time Estimates
- Base: ~1 hour
- Primary: ~8 hours
- Secondary: ~12 hours

## Quality Checks
1. Check base is flat
2. Verify coil forms are round
3. Test fit concentricity
4. Verify wire channels
