# QHRC Coil Winding Guide

## Wire Specifications
```
Primary Coil:
- 4,500 turns
- AWG 26 copper wire
- Length needed: ~150m
- Resistance: ~30Ω

Secondary Coil:
- 6,200 turns
- AWG 26 copper wire
- Length needed: ~250m
- Resistance: ~42Ω
```

## Winding Process
```
1. Primary Coil (4,500 turns)
   [====================]
   Layer 1: 450 turns
   Layer 2: 450 turns
   ...
   Layer 10: 450 turns

2. Secondary Coil (6,200 turns)
   [====================]
   Layer 1: 620 turns
   Layer 2: 620 turns
   ...
   Layer 10: 620 turns
```

## Winding Tips
```
1. Keep tension constant
2. Count turns carefully
3. Insulate between layers
4. Leave 20cm leads
5. Test continuity
```

## Testing
```
For each coil:
1. Measure DC resistance
2. Check for shorts
3. Verify turn count
4. Test inductance
```
