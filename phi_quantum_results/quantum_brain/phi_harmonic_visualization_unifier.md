# Phi-Harmonic Visualization Unifier

## Purpose
This script demonstrates the unified workflow for the modular Phi-Harmonic Brain System, integrating simulation, brain, cancer, and treatment models with the Enhanced Visualizer. It produces phi-harmonic, resonance, quantum, and timeline visualizations from representative or real data.

## Features
- **Modular Integration:** Imports existing modules without modifying them.
- **Unified Pipeline:** Runs a sample workflow for visualization of phi-harmonic and quantum data.
- **Extensible:** Can be extended to pull real simulation/model data for advanced analysis.

## Usage
Run the script to generate all visualizations:
```bash
python phi_harmonic_visualization_unifier.py
```

## Visualizations
1. **Phi Spiral:** Shows resonance or growth patterns along a golden spiral.
2. **Quantum Resonance Map:** 3D scatter of phi, pi, and e resonance values.
3. **Quantum State Projection:** 2D projection of complex quantum state amplitudes.
4. **Fibonacci Treatment Timeline:** Treatment effectiveness over Fibonacci time steps.
