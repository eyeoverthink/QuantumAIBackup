## Troubleshooting

### Component Not Found

If a component is not found by the orchestrator, check the following:

1. Ensure the component file exists in the project directory or a subdirectory.
2. Verify that the component class name matches the expected name.
3. Check that the component follows the phi-harmonic component decorator pattern.

### Communication Issues

If components are not communicating properly, check the following:

1. Ensure all components are using the phi-harmonic protocol.
2. Verify that event handlers are properly registered.
3. Check that component states are being updated regularly.

### Quantum State Issues

If quantum state values are incorrect, check the following:

1. Ensure coherence values are within the optimal range (0.9-0.999).
2. Verify that resonance values are phi-aligned.
3. Check that phi alignment values are high (>0.9).
