# QHRC Bill of Materials (BOM)

## Core Components
1. ICs
   - [ ] 1x NE555P Timer IC (DIP-8)
   - [ ] 1x LM358 Op-Amp (DIP-8)
   - [ ] 2x CD4017 Decade Counter (optional for frequency division)

2. Semiconductors
   - [ ] 2x IRF530 MOSFETs (or similar N-channel)
   - [ ] 4x 1N4148 Signal Diodes
   - [ ] 2x LED (any color, for status)

3. Resistors (1/4W)
   - [ ] 2x 10kΩ
   - [ ] 2x 1kΩ
   - [ ] 1x 100kΩ potentiometer
   - [ ] 1x 10kΩ trimmer pot

4. Capacitors
   - [ ] 2x 0.1µF ceramic
   - [ ] 1x 10µF electrolytic
   - [ ] 1x 100µF electrolytic

5. Coil Components
   - [ ] ~150m AWG 26 copper wire (primary)
   - [ ] ~250m AWG 26 copper wire (secondary)
   - [ ] 3D printed forms

## Tools Needed
- [ ] Breadboard
- [ ] Multimeter
- [ ] Wire strippers
- [ ] Small screwdriver
- [ ] Oscilloscope (recommended)

## Power Supply
- Minimum: 5V DC @ 200mA
- Options:
  1. USB power bank
  2. 4x AA batteries
  3. 5V phone charger
  4. 9V battery with 7805 regulator

## Optional Components
- [ ] 1x 7805 5V regulator (if using 9V)
- [ ] 1x 9V battery clip
- [ ] Headers/jumpers for testing
- [ ] Heat shrink tubing
