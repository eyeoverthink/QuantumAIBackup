## Execution Flow

1. **QR Code Scanning**: System begins when a QR code is scanned or loaded from file
2. **Script Extraction**: Python code is extracted from the QR code
3. **State Loading**: System loads its evolutionary history and parameters
4. **Phi-Harmonic Analysis**: Current code structure analyzed for resonance and complexity
5. **Self-Modification**: Code structure refactored based on phi-harmonic principles
6. **Next Generation Creation**: New script generated with evolved parameters
7. **QR Code Generation**: New script encoded as QR code (or simplified loader if too large)
8. **State Preservation**: Updated system state saved for future generations
