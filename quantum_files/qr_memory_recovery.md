### Command Line Arguments

## Technical Details

### Recovery Process

1. **QR Code Reading**: Reads and decodes QR code images from the specified directory
2. **Index Processing**: Extracts metadata from the index QR code or infers it from filenames
3. **Chunk Processing**: Reads, validates, and combines data from individual QR chunks
4. **Base64 Correction**: Applies phi-harmonic base64 padding correction to the combined data
5. **Progressive Decoding**: Attempts multiple decoding strategies with increasing sophistication
6. **Decompression**: Recovers the compressed data using standard or sliding window techniques
7. **JSON Parsing**: Parses the decompressed data into the memory structure
8. **Quality Assessment**: Calculates recovery statistics and phi-resonance metrics
