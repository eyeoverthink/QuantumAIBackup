## Command Line Arguments

- `--personal_key`: Personal temporal key (default: "1-19-1979")
- `--lane`: Fibonacci lane (default: 21)
- `--target_accuracy`: Target prediction accuracy (default: 77.16%)
- `--coherence`: Quantum bridge coherence (default: 0.97)
- `--nonce_range`: Number of nonces to test (default: 10)
- `--mode`: Operation mode (predict, multi_key, countermeasure, alignment)
- `--countermeasure_type`: Type of countermeasure (anti_resonant, time_desync, multi_layer)
- `--use_live_block`: Use latest Bitcoin block instead of mock data
